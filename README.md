# Lopez Family Trust

A workspace for planning, building, and maintaining the Lopez Family Trust.

> **This repository is PUBLIC.** Anyone on the internet can read it.
> Keep only non-sensitive planning material here, or make the repository
> private (Settings → General → Danger Zone → Change visibility) before adding
> anything personal. See [What never goes in this repo](#what-never-goes-in-this-repo).

> **Not legal advice.** This repo organizes the work. The trust itself should
> be drafted or reviewed by a licensed estate-planning attorney in the state
> where the trust will be established.

## What never goes in this repo

Git keeps every version of every file forever. Deleting something later
does not remove it from history. Never commit:

- Social Security numbers, tax IDs (EIN), or dates of birth
- Bank, brokerage, retirement, or insurance account numbers
- Signed originals or scans of executed documents, deeds, or IDs
- Passwords, PINs, or security questions
- Full home addresses or private contact details of family members

Instead, record a *reference*, for example "Brokerage account ending in
last-4, see the fireproof safe, folder B". Keep signed originals in a safe
place and digital copies in encrypted storage.

## How to work here

- Use a branch per change and open a pull request, so edits are reviewable.
- Date meeting notes and decisions (`YYYY-MM-DD-topic.md`).
- Record *why* a decision was made, not just what it was.
